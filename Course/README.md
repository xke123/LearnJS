## 现代 JavaScript 教程中文版

运行：

```bash
bash scripts/sync-resources.sh course
```

教材完整工作树下载到：

```text
Course/modern-javascript/
```

原始项目： https://github.com/javascript-tutorial/zh.javascript.info

按原始章节顺序阅读 `article.md`、独立完成 `task.md`，`solution.md` 仅用于完成后核对。课程文件不直接修改，专题练习放在 `learning/javascript/deep-dives/`。

该副本在本地，由 Git 忽略；更新课程可再次运行同步脚本。
