# JavaScript 独立专题练习区

**按需创建**，不是第二套课程。

当阅读《现代 JavaScript 教程中文版》遇到疑问时，请 AI 使用 deep-learn Skill 在此新建一个主题文件夹，例如：

```text
deep-dives/
  this-binding/
    practice.js
    notes.md
    mistakes.md
```

- `practice.js`：自己写代码、运行、调试。
- `notes.md`：专题理解与关键机制。
- `mistakes.md`：典型错误及纠正理由。

不必每章都建目录，也不记录「下一章是什么」。教材原始 `article.md`、`task.md`、`solution.md` 不在这里复制或修改。
